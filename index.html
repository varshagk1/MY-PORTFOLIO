How the Platform Works

Users access the e-learning platform through a web browser. The frontend provides the user interface for registration, login, courses, enrollment and learning. The PHP server-side application handles the main platform operations. MySQL stores user, course, enrollment, progress and administrative data. The admin can access the dashboard to manage categories and courses. The AI chatbot receives a user question, processes it using NLP, identifies the user's intent, retrieves relevant information and returns an AI response.
